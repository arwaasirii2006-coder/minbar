## لم يُنفَّذ بعد (يحتاج المفتاح والتسجيلات)

لم تتوفر على جهاز التطوير تسجيلات الخطب الخمس ولا مفتاح OpenAI، لذلك **لم تُقَس بعد** دقة التحويل، ولا جودة الترجمة الآلية، ولا زمن التأخير الفعلي على صوت حقيقي. لا توجد هنا أي أرقام مختلقة.

### المنهجية المقترحة للتسجيلات الخمس

التسجيلات تبقى خارج المستودع (`.gitignore` يمنع ملفات الصوت ومجلد `demo-recordings/`).

```bash
# 1) شغّل الخادم مع المفتاح والرمز
set OPENAI_API_KEY=...
set MINBAR_BROADCAST_CODES=KHATAM-2026=رمز
uvicorn main:app --port 8000

# 2) قيّم التسجيلات (أقل من 25 ميغابايت لكل ملف)
python scripts/evaluate_sermons.py --code رمز "D:/sermons/1.mp3" ... --out D:/sermons/results.json
```

لكل تسجيل يُسجَّل: زمن المعالجة، وزمن وصول أول مقطع للمستمع، وعدد المقاطع، والآيات المكتشفة (رقمها ودرجة المطابقة)، والمقاطع غير الواضحة، وإخفاقات الترجمة لكل لغة، وهل وصلت رسالة الانتهاء إلى المستمعين باللغات الثلاث.

ثم يُراجع يدويًا:
1. **الآيات:** هل كل آية تلاها الخطيب اكتُشفت؟ وهل كل آية اكتُشفت تلاها فعلًا؟ (الدقة والاستدعاء)
2. **التحويل:** عيّنة 20 جملة لكل خطبة مقابل الصوت (أخطاء الكلمات).
3. **الترجمة:** مراجعة ناطق بكل لغة لعيّنة 10 جمل (المعنى، المصطلحات).
4. **الزمن:** للبث المباشر، يُقاس من نطق الجملة إلى ظهورها عند المصلي.

تُضاف النتائج إلى هذا الملف بعد التشغيل.
