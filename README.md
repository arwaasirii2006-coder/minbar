# منبر | Minbar

منبر هو نظام يهدف إلى تحويل صوت الخطيب باللغة العربية إلى نص، ثم ترجمته إلى لغات مختلفة لمساعدة غير الناطقين بالعربية على متابعة محتوى الخطبة وفهمه.

## فكرة المشروع

يعتمد منبر على استقبال الصوت العربي وتحويله إلى نص، ثم معالجة النص وترجمته إلى اللغة التي يختارها المستخدم.

اللغات المدعومة حاليًا:

- الإنجليزية
- الأردية
- الهندية

## آلية العمل

يمر النظام بالمراحل التالية:

الصوت العربي → تحويل الصوت إلى نص → التحقق من النص → تجميع الجمل → التحقق من الآيات والمصطلحات → الترجمة → إرسال النتيجة للمستخدم.

## التشغيل

لتشغيل الخادم محليًا:

python -m uvicorn main:app --reload

بعد تشغيل الخادم يمكن الوصول إلى واجهة توثيق API من خلال:

/docs

## الملفات الرئيسية

main.py  
تشغيل تطبيق FastAPI وربط أجزاء المشروع.

rooms.py  
إدارة الغرف والتواصل.

transcribe.py  
تحويل الصوت العربي إلى نص وترجمته.

translate.py  
ترجمة النصوص إلى اللغة المطلوبة.

segmenter.py  
تجميع أجزاء النص حتى تكتمل الجملة.

verses.py  
التعامل مع الآيات القرآنية.

validate.py  
التحقق من النص قبل معالجته.

logger.py  
تسجيل معلومات التشغيل والأخطاء.

run_eval.py  
اختبار النظام وقياس أدائه.

## منهجية التقييم

يتم تقييم النظام من خلال مجموعة من المؤشرات، منها:

- زمن الاستجابة والتأخير.
- دقة المصطلحات.
- دقة التعرف على الآيات.
- تكلفة التشغيل.

## القيود الحالية

لا تزال قاعدة الآيات وقاعدة المصطلحات قيد التطوير.

تعتمد جودة النتائج على وضوح التسجيل الصوتي.

قد تتأثر عملية تحويل الصوت بالضوضاء وسرعة المتحدث.

تحتاج بعض أجزاء النظام إلى اختبارات إضافية قبل الاستخدام النهائي.

## حالة المشروع

المشروع حاليًا في مرحلة التطوير والاختبار.
