# منبر | Minbar

منبر هو نظام ذكي لمعالجة محتوى الخطب والمحاضرات العربية، حيث يقوم بتحويل الصوت العربي إلى نص، ثم معالجة النص وترجمته إلى لغات مختلفة، مع دعم التحقق من الآيات القرآنية والمصطلحات المهمة.

يهدف المشروع إلى مساعدة غير الناطقين باللغة العربية على متابعة محتوى الخطب وفهمه بصورة أسهل.

## فكرة المشروع

يعتمد منبر على استقبال الصوت العربي وتحويله إلى نص، ثم معالجة النص وتجميع الجمل، والتحقق من الآيات القرآنية والمصطلحات، ثم ترجمة المحتوى إلى اللغة التي يختارها المستخدم.

اللغات المدعومة حاليًا:

- الإنجليزية en
- الأردية ur
- الهندية hi

## آلية العمل

يمر النظام بالمراحل التالية:

الصوت العربي  
↓  
تحويل الصوت إلى نص  
↓  
تجميع الجمل ومعالجة النص  
↓  
التعرف على الآيات القرآنية  
↓  
التحقق من المصطلحات  
↓  
الترجمة  
↓  
إرسال النتيجة للمستخدم

## التقنيات المستخدمة

تم تطوير المشروع باستخدام:

- Python
- FastAPI
- Uvicorn
- OpenAI API
- Whisper لتحويل الصوت إلى نص
- GPT-5 mini للترجمة
- RapidFuzz لمطابقة الآيات القرآنية
- JSON لتخزين بعض البيانات ونتائج التقييم

## ملفات المشروع الرئيسية

main.py  
الملف الرئيسي لتشغيل واجهة API.

transcribe.py  
مسؤول عن تحويل الصوت العربي إلى نص.

translate.py  
مسؤول عن ترجمة النص إلى اللغة المطلوبة.

segmenter.py  
مسؤول عن تجميع النص وتقسيمه إلى جمل مناسبة.

verses.py  
مسؤول عن اكتشاف الآيات القرآنية ومطابقتها.

validate.py  
مسؤول عن عمليات التحقق من النصوص.

logger.py  
مسؤول عن تسجيل الأحداث والأخطاء.

run_eval.py  
مسؤول عن تشغيل تقييم النظام وحساب مؤشرات الأداء.

## التشغيل محليًا

أولًا تثبيت المتطلبات:
pip install -r requirements.txt

يجب إنشاء ملف .env وإضافة مفتاح OpenAI:
OPENAI_API_KEY=YOUR_OPENAI_API_KEY

ثم تشغيل الخادم:
python -m uvicorn main:app --reload

بعد التشغيل يمكن فتح واجهة توثيق API من خلال:
http://127.0.0.1:8000/docs

## واجهات API

يتضمن النظام الواجهات الأساسية التالية:

- GET /
- GET /health
- POST /transcribe
- POST /translate

## التقييم

يمكن تشغيل تقييم النظام باستخدام:
python run_eval.py

يقيس التقييم عدة مؤشرات، منها:

- زمن الاستجابة
- دقة المصطلحات
- دقة مطابقة الآيات
- التكلفة التقديرية

في الاختبار التجريبي تم الوصول إلى:

- دقة المصطلحات: 100%
- دقة مطابقة الآيات: 100%

ويتم حفظ نتائج التقييم في:
evaluation_results.json

## منهجية تقييم الآيات

يتم تطبيع النص العربي وإزالة بعض العلامات والاختلافات الكتابية، ثم مقارنة النص ببيانات الآيات باستخدام المطابقة النصية التقريبية.

يعيد النظام رقم السورة ورقم الآية ودرجة المطابقة عند تحقق الحد المطلوب للمطابقة.

## منهجية تقييم المصطلحات

يتم تحديد مجموعة من المصطلحات المتوقعة، ثم التحقق من وجودها داخل النص وحساب نسبة المصطلحات الموجودة مقارنة بإجمالي المصطلحات المتوقعة.

## تقدير التكلفة

يحتوي ملف التقييم على تقدير تقريبي لتكلفة معالجة النص باستخدام نموذج GPT-5 mini.

هذا الرقم تقديري لأغراض تقييم المشروع، ولا يمثل بالضرورة قيمة الفاتورة الفعلية لاستخدام OpenAI API.

## القيود الحالية

المشروع ما زال في مرحلة التطوير، ومن أبرز القيود الحالية:

- دقة تحويل الصوت تعتمد على جودة التسجيل ووضوح المتحدث.
- الضوضاء قد تؤثر على دقة التفريغ الصوتي.
- اكتشاف الآيات يعتمد على جودة النص الناتج من التفريغ.
- مطابقة الآيات القصيرة جدًا قد تكون محدودة حسب إعدادات المطابقة.
- الترجمة الآلية قد تحتاج إلى مراجعة بشرية في بعض السياقات.
- حساب التكلفة في ملف التقييم تقديري.
- اللغات المدعومة حاليًا محدودة بالإنجليزية والأردية والهندية.

## النشر

تم إعداد المشروع ليعمل كتطبيق FastAPI ويمكن نشره على خدمات الاستضافة السحابية مثل Render.

## الهدف المستقبلي

يهدف منبر مستقبلًا إلى توفير تجربة أكثر تكاملًا للترجمة شبه الفورية للخطب والمحاضرات، وتحسين دقة معالجة المصطلحات والآيات، وإضافة المزيد من اللغات وتحسين تجربة المستخدم.
